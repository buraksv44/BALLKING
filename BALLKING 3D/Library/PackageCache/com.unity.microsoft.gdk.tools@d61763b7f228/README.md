# com.unity.microsoft.gdk.tools

**Package Status: Supported**

This package adds GDK workflow support to the Unity Editor and is recommended for use in combination with the 'com.unity.microsoft.gdk' package. This package is not required to use the GDK API but includes features that make the development of Unity projects using the Microsoft Game Development Kit (GDK) easier.

This package is provided by Unity and co-developed in partnership with the Microsoft Corporation.

## Compatibility

It is always recommended to use the latest version of the editor stream you have selected. The following is the lowest editor versions expected to work:

- Unity 6000.2 (6000.2.0a7)
- Unity 6000.1 (6000.1.0a10)
- Unity 6000.0 (6000.0.42f1)

## Documentation

Online: https://docs.unity3d.com/Packages/com.unity.microsoft.gdk.tools@1.0/manual/index.html
Local: Package documentation is included in the `Documentation~` folder (hidden in the editor).
